# 🌍 Perfil de Viagens (Travelgram)

Um projeto criado para **treinar o uso do Flexbox** no CSS, simulando uma **página de perfil de viagens** inspirada em redes sociais.  
O objetivo é praticar conceitos de layout responsivo, alinhamento de elementos e espaçamento utilizando **Flexbox**.

---

## 💡 Objetivo do Projeto

O **Travelgram** tem como foco o **aperfeiçoamento das habilidades em Flexbox**, explorando propriedades como:

- `display: flex;`
- `justify-content`
- `align-items`
- `flex-wrap`
- `gap`  
- E o uso de **containers e itens flexíveis** para montar um layout organizado e moderno.

---

## 🧠 Conceitos Aplicados

- Estrutura semântica em **HTML5**  
- Organização visual utilizando **CSS3 com Flexbox**  
- Responsividade e espaçamento com `rem`  
- Boas práticas de estilização e hierarquia visual
